# Programación de Redes: Protocolos y APIs

Material educativo interactivo de la asignatura **Programación de Redes: Protocolos y APIs**.

## Organización del repositorio

```text
.
├── index.html
├── temas/
│   ├── bloque-1/
│   │   ├── tema-1-1/
│   │   ├── tema-1-2/
│   │   ├── tema-1-3/
│   │   └── tema-1-4/
│   └── bloque-2/
│       ├── tema-2-1/
│       ├── tema-2-2/
│       ├── tema-2-3/
│       └── tema-2-4/
└── recursos/
    ├── documentos/
    └── imagenes/
```

Cada tema principal y sus subtemas se agrupan en una carpeta propia. Ejemplo:

```text
temas/bloque-1/tema-1-1/
├── 1.1.html
├── 1.1.1.html
├── 1.1.2.html
└── ...
```

Los archivos HTML deben mantener navegación hacia sus subtemas cuando corresponda y un enlace visible de regreso al índice principal de la asignatura.
