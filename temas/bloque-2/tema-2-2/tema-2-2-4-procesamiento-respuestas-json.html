Cómo trabajar este tema

No proceses JSON sin validar contexto

Antes de acceder a claves o recorrer listas, comprueba que la respuesta es adecuada y que su estructura coincide con el contrato de la API.

1. Convertir una respuesta JSON en estructuras Python.
2. Diferenciar objetos, listas y valores anidados.

4. Extraer información útil para una aplicación de red.

Explora

JSON se transforma en tipos Python

Comprender esta correspondencia evita muchos errores al procesar respuestas.

object

dict

Un objeto JSON se convierte normalmente en un diccionario Python.

array

list

Un arreglo JSON se convierte normalmente en una lista Python.

valor

str · int · float

Cadenas y números se convierten en tipos equivalentes de Python.

estado

bool · None

true/false se convierten en booleanos y null en None.

JSONPythonEjemplo
objectdict{"id":15,"estado":"up"}
arraylist[{"id":15},{"id":18}]
stringstr"AZG-01"
numberint/float15 · 12.5
true/falsebooltrue → True
nullNonenull → None
JSON válido no significa datos válidos para tu aplicación. Una respuesta puede ser JSON correcto y aun así carecer de campos obligatorios o contener tipos inesperados.

Explica

Patrones seguros de procesamiento

Conviene separar decodificación, validación y uso de los datos.

Objeto individual

respuesta.raise_for_status() datos = respuesta.json() if not isinstance(datos, dict): raise ValueError("Se esperaba un objeto") requeridos = {"id", "estado"} faltantes = requeridos - datos.keys() if faltantes: raise ValueError( f"Faltan campos: {faltantes}" ) print(datos["estado"])

Primero valida estructura y campos antes de consumirlos.

Lista de recursos

datos = respuesta.json() if not isinstance(datos, list): raise ValueError("Se esperaba una lista") for enlace in datos: if not isinstance(enlace, dict): continue identificador = enlace.get("id") estado = enlace.get("estado") print(identificador, estado)

get() permite acceder a claves opcionales sin lanzar KeyError.

Estructura anidada

datos = respuesta.json() metricas = datos.get("metricas", {}) latencia = metricas.get("latencia_ms") perdida = metricas.get("perdida_pct") print(latencia, perdida)

Usar valores por defecto evita errores cuando una sección opcional no existe.

JSON inválido

import requests try: datos = respuesta.json() except requests.exceptions.JSONDecodeError: print( "La respuesta no contiene JSON válido" )

Una respuesta HTTP puede tener éxito y aun así no contener JSON válido.

Ejercicio resuelto

Contar enlaces en alerta

Una API devuelve una lista JSON con el estado de varios enlaces.

Problema

Validar y obtener un indicador simple

1
Decodificar.
Usar respuesta.json().
2
Validar tipo.
Confirmar que la raíz sea una lista.
3
Recorrer.
Procesar cada elemento si es un diccionario.
4
Filtrar.
Contar elementos cuyo estado sea alerta.
5
Interpretar.
Usar el resultado como indicador del conjunto recibido, no como disponibilidad global de la red.
datos = respuesta.json() if not isinstance(datos, list): raise ValueError( "Se esperaba una lista" ) alertas = 0 for enlace in datos: if ( isinstance(enlace, dict) and enlace.get("estado") == "alerta" ): alertas += 1 print("Enlaces en alerta:", alertas)
