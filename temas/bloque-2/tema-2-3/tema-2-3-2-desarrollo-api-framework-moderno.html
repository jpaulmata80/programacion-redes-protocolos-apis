Explora

El framework conecta HTTP con funciones Python

Un decorador asocia un método y una ruta con una función que procesa la solicitud y genera una respuesta.

Aplicación

FastAPI()

Representa la aplicación web sobre la que se registran los endpoints.

Decorador

@app.get(...)

Asocia una ruta y un método HTTP con una función de Python.

Parámetro

Path / Query

FastAPI obtiene valores desde la ruta o desde la query según la firma de la función.

Respuesta

dict → JSON

Un diccionario retornado por la función se serializa como respuesta JSON.

DiseñoFastAPIResultado
GET /api/enlaces@app.get("/api/enlaces")Lista o representación de la colección.
GET /api/enlaces/{id}@app.get("/api/enlaces/{enlace_id}")Recurso individual.
?estado=alertaParámetro opcional en la funciónFiltro de consulta.
Respuesta JSONreturn {"id": 15}FastAPI serializa el diccionario.
FastAPI no es el servidor de producción por sí solo. La aplicación sigue el estándar ASGI y necesita un servidor ASGI, como Uvicorn, para recibir conexiones HTTP.

Explica

Construye una API mínima paso a paso

Un único archivo permite comprender la arquitectura antes de separar el proyecto en módulos.

1. Instalar dependencias

python -m pip install fastapi uvicorn

FastAPI y Uvicorn son dependencias externas del proyecto.

2. Crear la aplicación

from fastapi import FastAPI app = FastAPI( title="API de Red" )

La variable app representa la aplicación ASGI.

3. Declarar un endpoint

@app.get("/api/enlaces") def listar_enlaces(): return { "items": [ { "id": 15, "estado": "up" } ] }

El decorador registra la ruta y el método.

4. Parámetro de ruta

@app.get( "/api/enlaces/{enlace_id}" ) def obtener_enlace( enlace_id: int ): return { "id": enlace_id, "estado": "up" }

El valor de la ruta se entrega como argumento de la función.

5. Query parameter

@app.get("/api/alarmas") def listar_alarmas( estado: str | None = None ): return { "filtro_estado": estado }

Un argumento que no forma parte de la ruta puede interpretarse como query parameter.

6. Ejecutar localmente

uvicorn main:app --reload

main es el nombre del archivo y app la variable FastAPI.

Uso didáctico de --reload: facilita el desarrollo local al recargar cambios automáticamente. No debe asumirse como configuración de producción.
