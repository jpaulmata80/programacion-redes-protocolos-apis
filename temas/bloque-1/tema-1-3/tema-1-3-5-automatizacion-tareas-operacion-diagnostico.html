Cómo trabajar este tema

Automatizar una rutina completa

La meta no es ejecutar muchas cosas, sino construir una secuencia que pueda repetirse con criterios claros y resultados comparables.

1. Integrar inventario, comprobación y registro.
2. Clasificar resultados según reglas definidas.
3. Diseñar una rutina de diagnóstico reproducible.
4. Justificar cuándo una alerta requiere escalamiento humano.
Alcance. El objetivo es diagnóstico y operación básica. La automatización no reemplaza el juicio técnico cuando existe impacto, ambigüedad o necesidad de cambios críticos.
Explora

Una automatización operativa necesita criterios

El script debe saber qué revisar, cómo interpretar el resultado y cuándo detenerse o escalar.

Selección

Qué se revisa

El inventario puede filtrarse por sitio, tipo de equipo, criticidad o grupo operativo.

Comprobación

Qué se mide

Alcance, servicio disponible, respuesta remota, estado de interfaz o dato operativo.

Clasificación

Cómo se interpreta

Reglas simples convierten salidas en estados como OK, advertencia, error o timeout.

Escalamiento

Qué requiere una persona

Una automatización debe saber cuándo generar evidencia y detenerse en lugar de tomar una decisión riesgosa.

Regla útil: automatiza primero la recolección y clasificación; automatiza acciones correctivas solo cuando existan criterios, permisos, pruebas y mecanismos de reversión claros.
Predice

Una estación falla en dos comprobaciones

El ping responde, pero el servicio remoto esperado no está disponible y la consulta SSH expira por timeout.

Una comprobación aislada no describe necesariamente el estado completo del servicio.

Explica

Separar comprobaciones y clasificación

Esta separación hace que el flujo sea más fácil de mantener y probar.

Comprobación por equipo

def diagnosticar(equipo): return { "equipo": equipo["nombre"], "ping": comprobar_ping(equipo), "servicio": comprobar_servicio(equipo), "remoto": consultar_estado(equipo) }

Cada función puede manejar sus propios timeout y errores.

Clasificación

def clasificar(resultado): if not resultado["ping"]: return "error" if not resultado["servicio"]: return "alerta" if resultado["remoto"] == "timeout": return "alerta" return "ok"

Las reglas deben estar documentadas y ser coherentes con la operación real.

Recorrer inventario

resultados = [] for equipo in inventario: diagnostico = diagnosticar(equipo) diagnostico["estado"] = clasificar(diagnostico) resultados.append(diagnostico)

Generar resumen

resumen = { "ok": 0, "alerta": 0, "error": 0 } for r in resultados: resumen[r["estado"]] += 1

El resumen permite priorizar revisión y escalamiento.

Ejercicio resuelto

Rutina diaria para tres estaciones

Queremos revisar conectividad, servicio y consulta remota, sin ejecutar cambios.

Problema

Construir una rutina reproducible y auditable

1
Definir inventario.
Seleccionar las estaciones que pertenecen al turno o grupo operativo.
2
Aplicar comprobaciones.
Ejecutar alcance, servicio y consulta remota con timeout.
3
Clasificar.
Aplicar reglas conocidas para producir OK, alerta o error.
4
Registrar.
Guardar por estación qué prueba falló y cuál fue el error.
5
Escalar.
Entregar al operador un resumen con los equipos que requieren atención.
Resultado esperado: la automatización reduce trabajo repetitivo, pero el operador conserva la decisión sobre acciones correctivas de mayor impacto.
