Cómo trabajar este tema

SSH no es solo “conectarse”

Una automatización segura debe verificar a qué servidor se conecta, usar credenciales protegidas y cerrar la sesión correctamente.

Explora

Cuatro decisiones antes de ejecutar un comando

La seguridad comienza antes de llamar a exec_command().

Servidor

Identidad conocida

El cliente debe comprobar la clave del servidor mediante un archivo de hosts conocidos o una política explícita de confianza.

Usuario

Autenticación

Puede usarse una clave privada protegida o un mecanismo autorizado. No conviene incrustar contraseñas en el código.

Canal

Sesión cifrada

SSH protege confidencialidad e integridad del canal entre cliente y servidor.

Comando

Acción controlada

La aplicación debe ejecutar únicamente operaciones previstas y procesar tanto salida normal como errores.

Host key ≠ clave del usuario. La clave del servidor ayuda a verificar la identidad del equipo remoto; la clave del usuario se utiliza para autenticar al cliente ante ese servidor.
PrácticaRecomendaciónMotivo
Cargar hosts conocidosload_system_host_keys()Permite comprobar la identidad previamente confiada del servidor.
Host desconocidoRechazar por defecto y verificar antes de confiarEvita aceptar silenciosamente una identidad no validada.
CredencialesClaves o mecanismos protegidosEvita exponer secretos dentro del código fuente.
CierreUsar try/finally o contexto apropiadoLibera la sesión y recursos aun si ocurre un error.
Predice

El servidor cambia de clave

Tu script ya conocía la identidad del servidor, pero ahora la clave del host no coincide con la registrada.

La clave del host existe precisamente para ayudar a detectar cambios de identidad.

Explica

Conexión básica con Paramiko

Paramiko es una dependencia externa, por lo que debe instalarse dentro del entorno virtual del proyecto.

Preparar la dependencia

python -m venv .venv # activar el entorno virtual python -m pip install paramiko

No forma parte de la biblioteca estándar de Python.

Crear un cliente seguro

import paramiko cliente = paramiko.SSHClient() cliente.load_system_host_keys() cliente.set_missing_host_key_policy( paramiko.RejectPolicy() )

La política de rechazo evita confiar automáticamente en hosts desconocidos.

Conectar con clave

cliente.connect( hostname="192.0.2.10", port=22, username="operador", key_filename="/ruta/segura/id_ed25519", timeout=5 )

La dirección usada pertenece a un rango reservado para documentación.

Ejecutar y leer resultados

stdin, stdout, stderr = cliente.exec_command( "show status" ) salida = stdout.read().decode() errores = stderr.read().decode() print(salida) cliente.close()

El comando real dependerá del sistema o dispositivo administrado.

No copies secretos al código. Evita patrones como password="MiClave123". Las credenciales deben gestionarse fuera del código fuente y con permisos apropiados.
Ejercicio resuelto

Consultar el nombre de un servidor remoto

Diseñamos una función que abre una sesión, ejecuta un comando de lectura y devuelve una salida limpia.

Problema

Conectar, consultar y cerrar de forma controlada

1
Preparar el cliente.
Cargar claves de hosts conocidas y rechazar identidades desconocidas.
2
Autenticar.
Usar una clave autorizada almacenada fuera del código.
3
Ejecutar.
Enviar un comando de solo lectura.
4
Procesar.
Leer stdout y stderr.
5
Cerrar.
Garantizar el cierre aunque ocurra una excepción.
import paramiko def consultar_hostname(host, usuario, clave): cliente = paramiko.SSHClient() cliente.load_system_host_keys() cliente.set_missing_host_key_policy( paramiko.RejectPolicy() ) try: cliente.connect( hostname=host, username=usuario, key_filename=clave, timeout=5 ) _, stdout, stderr = cliente.exec_command( "hostname" ) salida = stdout.read().decode().strip() error = stderr.read().decode().strip() return salida, error finally: cliente.close()
