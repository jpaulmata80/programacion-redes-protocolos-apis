Cómo trabajar este tema

No basta con ejecutar: hay que interpretar

El valor profesional aparece cuando el script puede distinguir éxito, error, timeout y datos relevantes sin depender de que una persona lea toda la consola.

1. Ejecutar comandos externos con subprocess.run().
2. Interpretar stdout, stderr y returncode.
3. Procesar una salida textual para extraer información útil.
4. Aplicar timeout y construcción segura de argumentos.
Alcance. Trabajaremos con comandos locales de diagnóstico. El acceso remoto por SSH se estudiará en 1.3.3.
Explora

Cuatro elementos que debes observar

Un comando externo produce más información que el texto visible en pantalla.

Argumentos

Qué se ejecuta

Es preferible proporcionar comando y argumentos como una lista, por ejemplo ["ping", "-c", "1", host].

stdout

Salida estándar

Contiene normalmente el resultado esperado del comando cuando se usa capture_output=True.

stderr

Salida de error

Puede contener mensajes de error, advertencias o información adicional.

returncode

Estado del proceso

Un valor de retorno permite decidir programáticamente si una ejecución terminó de forma satisfactoria según la herramienta.

Seguridad y robustez: cuando los argumentos provienen de datos externos, evita construir una cadena para ejecutarla con shell=True. Usa listas de argumentos y valida los valores antes de ejecutar.

Explica

Ejecutar de forma controlada con subprocess.run()

Capturar texto y limitar el tiempo de espera permite integrar el comando dentro de una lógica de automatización.

Linux/macOS

import subprocess host = "192.0.2.10" resultado = subprocess.run( ["ping", "-c", "1", host], capture_output=True, text=True, timeout=3 ) print(resultado.returncode) print(resultado.stdout)

El host de ejemplo pertenece a un rango reservado para documentación.

Windows

import subprocess host = "192.0.2.10" resultado = subprocess.run( ["ping", "-n", "1", host], capture_output=True, text=True, timeout=3 ) print(resultado.returncode) print(resultado.stdout)

La diferencia está en los argumentos de la herramienta del sistema.

Manejar timeout

try: resultado = subprocess.run( comando, capture_output=True, text=True, timeout=3 ) except subprocess.TimeoutExpired: print("El comando superó el tiempo permitido")

Procesar una salida

lineas = resultado.stdout.splitlines() for linea in lineas: if "ttl=" in linea.lower(): print("Se detectó una respuesta ICMP")

El procesamiento textual depende del sistema y del formato real de la herramienta. No conviene asumir que todas las plataformas imprimen lo mismo.

Ejercicio resuelto

Comprobar una lista de hosts

Queremos ejecutar una comprobación por host y almacenar un resultado simple sin detener todo el script ante un timeout.

Problema

Clasificar cada host como respondiente, no respondiente o timeout

1
Entrada.
Partir de una lista de direcciones previamente validadas.
2
Construcción del comando.
Usar una lista de argumentos, no una cadena con shell=True.
3
Control de tiempo.
Aplicar timeout para que un host no detenga indefinidamente el recorrido.
4
Decisión.
Examinar el resultado y registrar el estado de cada host.
import subprocess hosts = ["192.0.2.10", "192.0.2.11"] for host in hosts: comando = ["ping", "-c", "1", host] try: r = subprocess.run( comando, capture_output=True, text=True, timeout=3 ) estado = "responde" if r.returncode == 0 else "sin respuesta" except subprocess.TimeoutExpired: estado = "timeout" print(host, estado)
Nota: el significado exacto de los códigos de retorno depende de la herramienta y plataforma. En una automatización real conviene comprobar la documentación del comando usado.
