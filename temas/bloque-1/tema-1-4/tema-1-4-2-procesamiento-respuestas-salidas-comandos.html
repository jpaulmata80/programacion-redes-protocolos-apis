Cómo trabajar este tema

Procesar es reducir ruido sin perder significado

Una salida de consola puede contener decenas de líneas. El programa debe quedarse con los datos relevantes y saber qué hacer si el patrón esperado no aparece.

1. Limpiar respuestas textuales con métodos básicos de cadenas.
2. Recorrer líneas y localizar información relevante.
3. Extraer valores mediante patrones simples y expresiones regulares básicas.
4. Validar el resultado antes de utilizarlo.
Alcance. Usaremos procesamiento textual sencillo y expresiones regulares solo cuando aporten valor. Los datos ya estructurados, como JSON, se desarrollarán en 1.4.3.
Explora

Cuatro herramientas básicas de parsing

Antes de recurrir a expresiones complejas, conviene aprovechar operaciones simples y legibles.

strip()

Limpiar extremos

Elimina espacios y saltos de línea sobrantes al inicio y al final de una cadena.

splitlines()

Separar líneas

Convierte una salida multilínea en una colección fácil de recorrer.

in / startswith()

Buscar patrones simples

Permiten localizar líneas que contengan una palabra clave o comiencen con un prefijo conocido.

re

Patrones más precisos

Las expresiones regulares ayudan cuando el dato cambia de posición pero mantiene una estructura reconocible.

Principio didáctico: usa la herramienta más simple que resuelva el problema. Un parser claro suele ser más mantenible que una expresión regular innecesariamente compleja.
Predice

Tu script busca una línea que contenga Estado:, pero el dispositivo responde con un formato diferente.

Un parser también debe reconocer cuándo no pudo obtener el dato.

Explica

Procesamiento paso a paso

Primero operaciones simples; después patrones más específicos.

Buscar una línea

salida = """ Interface: Gi0/1 Estado: UP Velocidad: 1000 Mbps """ estado = None for linea in salida.splitlines(): linea = linea.strip() if linea.startswith("Estado:"): estado = linea.split(":", 1)[1].strip() print(estado)

El segundo argumento de split() limita la división a una sola vez.

Extraer un número con regex

import re salida = "tiempo=18 ms" m = re.search( r"tiempo=(\d+)\s*ms", salida ) if m: latencia = int(m.group(1)) else: latencia = None

El grupo (\d+) captura uno o más dígitos.

Normalizar mayúsculas

texto = "Interface is UP" if "up" in texto.lower(): estado = "up"

Normalizar ayuda cuando la herramienta cambia mayúsculas y minúsculas.

Validar el resultado

if estado not in {"up", "down"}: resultado = { "estado": "error", "error": "Formato inesperado" }

Encontrar texto no significa que el valor sea válido.

Ejercicio resuelto

Extraer estado y velocidad de una interfaz

La respuesta contiene más texto del necesario. Queremos obtener dos valores concretos.

Problema

Convertir tres líneas en dos campos útiles

1
Separar líneas.
Aplicar splitlines().
2
Limpiar cada línea.
Usar strip().
3
Identificar prefijos.
Buscar Estado: y Velocidad:.
4
Extraer el valor.
Dividir por : una sola vez.
5
Validar.
Comprobar que ambos campos fueron encontrados.
def procesar_interfaz(salida): datos = { "estado": None, "velocidad": None } for linea in salida.splitlines(): linea = linea.strip() if linea.startswith("Estado:"): datos["estado"] = ( linea.split(":", 1)[1].strip() ) elif linea.startswith("Velocidad:"): datos["velocidad"] = ( linea.split(":", 1)[1].strip() ) if None in datos.values(): return { "estado_procesamiento": "error", "error": "Faltan campos esperados" } return { "estado_procesamiento": "ok", "datos": datos }

Reflexión

¿Qué haría robusto a un parser de red?

Piensa en cambios de formato, datos faltantes, mayúsculas/minúsculas, unidades y validación de valores.

El texto no se transmite; si lo guardas, permanece únicamente en el almacenamiento local de este navegador.

Referencias conceptuales

Python: métodos de cadenas, estructuras de control y módulo re. Los patrones mostrados son deliberadamente simples para fines docentes.

Delimitación

Este subtema procesa texto. Cuando la fuente ya entrega información estructurada, como JSON, conviene aprovechar esa estructura en lugar de analizar texto manualmente.
