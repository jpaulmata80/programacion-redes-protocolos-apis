Recolección programática de información de dispositivos y servicios

Diseña recolectores que consulten equipos y servicios de forma controlada, con timeout, manejo de errores y una salida uniforme que pueda procesarse después.

Comenzar recorrido Volver al Tema 1.4

Un recolector debe responder cuatro preguntas

1
¿Qué consulto?host · servicio · dispositivo · dato operativo
2
¿Cómo consulto?DNS · socket TCP · comando local · SSH autorizado
3
¿Qué puede fallar?timeout · resolución · conexión · autenticación
4
¿Qué devuelvo?origen · estado · valor · error · contexto
Cómo trabajar este tema

Recolectar no es copiar texto

Una buena función de recolección devuelve información predecible incluso cuando el dispositivo no responde.

1. Seleccionar una fuente adecuada de información.
2. Implementar consultas básicas con control de tiempo.
3. Diferenciar dato, estado y error.
4. Normalizar resultados para procesamiento posterior.
Alcance. Este subtema se concentra en obtener datos. La limpieza y extracción detallada de valores desde respuestas complejas corresponde a 1.4.2.
Explora

Cuatro fuentes frecuentes de información

No todas las consultas se resuelven con el mismo mecanismo.

DNS

Resolución de nombres

Permite obtener información de direccionamiento asociada a un nombre mediante funciones como socket.getaddrinfo().

TCP

Disponibilidad de servicio

Un intento de conexión controlado puede indicar si un servicio TCP acepta conexiones en una dirección y puerto.

Sistema

Herramientas locales

Comandos del sistema pueden aportar rutas, configuración IP u otros datos, siempre que se ejecuten de forma controlada.

SSH

Consulta remota autorizada

Permite obtener información directamente desde un servidor o equipo autorizado sin intervención manual.

Diseño recomendado: todas las funciones de recolección deberían devolver una estructura semejante, aunque utilicen mecanismos distintos. Eso simplifica el resto del programa.

Explica

Ejemplos de recolección básica

Cada función responde una pregunta concreta y convierte el resultado en una estructura uniforme.

Resolver un nombre

import socket def recolectar_dns(nombre): try: info = socket.getaddrinfo( nombre, None ) direcciones = sorted({ item[4][0] for item in info }) return { "fuente": "dns", "estado": "ok", "valor": direcciones, "error": "" } except socket.gaierror as exc: return { "fuente": "dns", "estado": "error", "valor": [], "error": str(exc) }

Comprobar un servicio TCP

import socket def recolectar_tcp(host, puerto): try: with socket.create_connection( (host, puerto), timeout=2 ): return { "fuente": "tcp", "estado": "ok", "valor": "disponible", "error": "" } except (TimeoutError, OSError) as exc: return { "fuente": "tcp", "estado": "error", "valor": "no disponible", "error": str(exc) }

Recolector genérico

def resultado(fuente, estado, valor=None, error=""): return { "fuente": fuente, "estado": estado, "valor": valor, "error": error }

La estructura común facilita almacenar y procesar resultados heterogéneos.

Agregar contexto del equipo

r = recolectar_tcp( "192.0.2.10", 22 ) r["equipo"] = "srv-noc-01" r["operacion"] = "ssh-disponible"

La dirección de ejemplo pertenece a un rango reservado para documentación.

Ejercicio resuelto

Recolectar disponibilidad SSH de tres servidores

Queremos comprobar el puerto TCP 22 y conservar un resultado por equipo.

Problema

Un fallo no debe detener todo el inventario

1
Definir inventario.
Cada servidor tiene nombre y host.
2
Aplicar el mismo recolector.
La función recibe host y puerto.
3
Agregar contexto.
El resultado se asocia al nombre del equipo.
4
Conservar todos los resultados.
Los éxitos y errores forman parte de la misma lista.
servidores = [ {"nombre": "srv-01", "host": "192.0.2.10"}, {"nombre": "srv-02", "host": "192.0.2.11"}, {"nombre": "srv-03", "host": "192.0.2.12"} ] resultados = [] for servidor in servidores: r = recolectar_tcp( servidor["host"], 22 ) r["equipo"] = servidor["nombre"] resultados.append(r)
Interpretación: aquí solo comprobamos disponibilidad TCP del servicio. No demostramos que la autenticación SSH sea válida ni que un comando remoto pueda ejecutarse.
