Cómo trabajar este tema

La estructura reduce ambigüedad

Si cada campo tiene un nombre conocido, el programa puede acceder a los datos directamente sin “adivinar” dónde aparecen dentro de un texto.

1. Representar información de red mediante listas y diccionarios.

Alcance. Trabajaremos JSON como formato principal y CSV como referencia básica. No entraremos todavía en esquemas formales, XML avanzado, bases de datos ni formatos binarios.
Explora

Cuatro ideas esenciales

JSON es texto, pero su estructura permite representar objetos, listas y valores de forma inequívoca.

dict

Objeto

Un diccionario Python representa pares clave–valor, por ejemplo {"equipo": "RTR-01"}.

list

Colección

Una lista agrupa varios valores u objetos, como un inventario de dispositivos.

JSON

Texto estructurado

Sirve para almacenar o intercambiar estructuras compatibles entre aplicaciones.

Validación

Confiar con cautela

Que un texto sea JSON válido no significa que tenga las claves o tipos que tu programa necesita.

Detalle importante: JSON no admite todos los tipos de Python. Por ejemplo, una tupla se serializa como arreglo JSON y un objeto personalizado requiere tratamiento adicional.

Explica

Serializar, deserializar y validar

El módulo json forma parte de la biblioteca estándar.

Python → JSON

import json dato = { "equipo": "RTR-01", "estado": "ok", "latencia_ms": 18, "alcanzable": True } texto = json.dumps( dato, ensure_ascii=False, indent=2 ) print(texto)

dumps() devuelve una cadena JSON.

JSON → Python

import json texto = """ { "equipo": "RTR-01", "estado": "ok", "latencia_ms": 18 } """ dato = json.loads(texto) print(dato["equipo"]) print(dato["latencia_ms"])

loads() interpreta una cadena JSON.

Leer un archivo JSON

import json with open( "inventario.json", "r", encoding="utf-8" ) as archivo: inventario = json.load(archivo)

load() trabaja con un archivo abierto.

Validar campos mínimos

REQUERIDOS = { "equipo", "estado", "latencia_ms" } faltantes = REQUERIDOS - dato.keys() if faltantes: print( "Faltan:", sorted(faltantes) )

La validación evita errores al acceder a claves que no existen.

Ejercicio resuelto

Procesar un inventario JSON de dispositivos

Recibimos una lista de objetos y necesitamos contar cuántos equipos están en estado de alerta.

Problema

Deserializar, recorrer y validar

1
Deserializar.
Convertir el texto JSON en estructuras Python.
2
Confirmar la raíz.
Verificar que el resultado sea una lista.
3
Recorrer objetos.
Comprobar que cada elemento contenga equipo y estado.
4
Contar.
Incrementar solo cuando estado == "alerta".
import json texto = """ [ {"equipo":"RTR-01","estado":"ok"}, {"equipo":"RTR-02","estado":"alerta"}, {"equipo":"RTR-03","estado":"alerta"} ] """ inventario = json.loads(texto) alertas = 0 for equipo in inventario: if ( "equipo" not in equipo or "estado" not in equipo ): continue if equipo["estado"] == "alerta": alertas += 1 print(alertas)
Resultado: se detectan 2 equipos en alerta. La estructura permite acceder directamente al campo estado sin analizar texto libre.

Caso profesional

Exportar resultados de monitoreo

Un NOC quiere almacenar resultados de múltiples equipos y reutilizarlos en otra aplicación.

Busca una representación que pueda ser procesada por otras herramientas sin perder contexto.
¿Y CSV? Para datos puramente tabulares y homogéneos, CSV puede ser suficiente. JSON resulta más cómodo cuando existen listas anidadas, objetos o campos de distinta naturaleza.
