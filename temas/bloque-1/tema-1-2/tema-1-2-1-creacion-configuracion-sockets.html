Subtema 1.2.1 · Programación de sockets

Creación y configuración de sockets

Antes de conectar un cliente o publicar un servicio, una aplicación debe crear un socket y definir qué familia de direcciones, tipo de comunicación y comportamiento básico utilizará.

DESARROLLO CONCEPTUAL

Cuatro ideas antes de crear un socket

La biblioteca estándar de Python expone la interfaz de sockets del sistema operativo. Al crear uno, la aplicación especifica cómo desea comunicarse.

Socket

Punto de comunicación

Es un objeto que la aplicación utiliza para operar sobre una comunicación de red. Encapsula estado y operaciones del sistema operativo.

  • Se crea antes de usarlo.
  • Debe cerrarse al terminar.
Familia

AF_INET / AF_INET6

Indica qué familia de direcciones utilizará el socket.

  • AF_INET: IPv4.
  • AF_INET6: IPv6.
Tipo

STREAM / DGRAM

Describe la semántica básica de comunicación solicitada al sistema operativo.

  • SOCK_STREAM: flujo.
  • SOCK_DGRAM: datagramas.
Configuración

Comportamiento adicional

Después de crearlo pueden ajustarse propiedades como tiempos de espera u opciones específicas.

  • settimeout(): limita una espera.
  • Otras opciones aparecerán cuando hagan falta.
NecesidadFamiliaTipoInterpretación
Aplicación sobre IPv4 con flujo orientado a conexiónAF_INETSOCK_STREAMPreparación típica para TCP/IPv4.
Aplicación sobre IPv4 basada en datagramasAF_INETSOCK_DGRAMPreparación típica para UDP/IPv4.
Aplicación sobre IPv6 con flujoAF_INET6SOCK_STREAMMisma idea de flujo, pero con direccionamiento IPv6.
Aplicación sobre IPv6 basada en datagramasAF_INET6SOCK_DGRAMDatagramas utilizando direcciones IPv6.
Importante: en los primeros ejercicios omitiremos el argumento de protocolo porque Python y el sistema operativo pueden seleccionar el protocolo adecuado a partir de la familia y el tipo. Esto evita añadir complejidad que todavía no aporta al objetivo del subtema.

EXPERIMENTA · OBSERVA · EXPLICA

Construye la creación de un socket

Selecciona los requisitos y observa cómo cambian los argumentos. El generador no ejecuta código: te ayuda a relacionar decisiones de red con la instrucción que escribirías en Python.

Configurador

Resultado conceptual

import socket sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

AF_INET selecciona IPv4 y SOCK_STREAM solicita una comunicación de flujo. Todavía no existe una conexión remota.

Laboratorio guiado · inspecciona el objeto creado

Este fragmento puede ejecutarse en tu entorno Python. Crea un socket, configura un timeout y consulta sus propiedades básicas.

import socket with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock: sock.settimeout(3.0) print("Familia:", sock.family) print("Tipo:", sock.type) print("Timeout:", sock.gettimeout())
Observa: el bloque with ayuda a liberar el recurso al terminar. La salida exacta de familia y tipo puede representarse mediante valores o enumeraciones según la versión de Python, pero debe corresponder a la configuración creada.

EJERCICIO RESUELTO

Traducir requisitos a una configuración

No empieces por la sintaxis. Empieza por identificar qué necesita la aplicación.

Problema
Una herramienta de administración de red utilizará IPv4, necesita una comunicación orientada a conexión y no debe quedar esperando más de 5 segundos en una operación bloqueante.
Paso 1 · Familia
El requisito dice IPv4, por lo tanto elegimos socket.AF_INET.
Paso 2 · Tipo
La aplicación necesita flujo orientado a conexión, por lo tanto elegimos socket.SOCK_STREAM.
Paso 3 · Creación
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
Paso 4 · Timeout
sock.settimeout(5.0). Esto no garantiza que la red responda: establece cuánto esperará una operación antes de producir una excepción de timeout.
Paso 5 · Cierre
Al terminar debe cerrarse el recurso. Una forma segura es utilizar un bloque with cuando el flujo del programa lo permita.
